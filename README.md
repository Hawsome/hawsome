### Sentinel Sync Engine
A fault-tolerant PHP data pipeline that mirrors data from a WordPress/Webflow CMS to a dedicated SQL database. Built with a "Failure-First" mentality.

- **Dead Letter Queue (DLQ)** captures failed syncs - zero data loss on interruption
- **Idempotency** via `ON DUPLICATE KEY UPDATE` - safe to re-run at any point
- **Self-Healing Recovery Worker** re-processes queued items once the system recovers
- Currency stored as integers in transit to eliminate floating-point rounding errors
- Full PDO Prepared Statements throughout

→ **[View Repo](https://github.com/Hawsome/sentinel-sync-engine)**
